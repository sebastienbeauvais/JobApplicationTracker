# Title
Job Application Dashboard

# Description
As a user, I want a clean dashboard that displays different metrics regarding my job application journey.

# Acceptance Criteria
- Clean dashboard (Can scroll down page for additional metrics)
- Clean UI (consistent across entire application)

# Logic

## Route
- Dashboard is the **homepage** (`/`)

## Metrics to Display
1. **Total Applications Count** - Total number of job applications tracked
2. **Applications by Status** - Breakdown showing count per status (Applied, Interviewing, Offer Received, Accepted, Rejected, Withdrawn)
3. **Interview Rate** - Percentage of applications that led to interviews (Got Interview = true)
4. **Applications Over Time** - Visual representation of application activity over time
5. **Recent Applications** - List of most recently added/updated applications

## Visualizations
- Specific visualization types (charts, graphs) to be determined later
- Should be clean and consistent with Apple website aesthetic

## Data Source
- All metrics derived from stored job application data
